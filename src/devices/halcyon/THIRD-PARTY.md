# Third-party software

Halcyon is licensed under Apache-2.0, as the rest of the ANARI SDK (`LICENSE` at the SDK's
root), but for the files that port the code
below, which carry its license with a credit of their source in their header. Its builds
include the following third-party code.

The ports of Typhoon and OpenUSD code are tagged `SPDX-License-Identifier:
LicenseRef-TOST-1.0`: the Tomorrow Open Source Technology License 1.0, whose text is
`external/typhoon/LICENSE.txt` (Apache 2.0 but for Section 6, Trademarks). TOST has no
SPDX identifier yet, so the tag is a `LicenseRef-`, as the Alliance for OpenUSD's
community uses it while the license is registered; SPDX's `Pixar` license has the same
text under Pixar's earlier name for it. A port that also takes code under another license
names both (`LicenseRef-TOST-1.0 AND Apache-2.0` for `renderer/pathtracer/Sampling.isph`,
with OpenQMC, and `renderer/pathtracer/Subsurface.*`, with Blender Cycles' code that
Typhoon takes; `LicenseRef-TOST-1.0 AND BSD-3-Clause` for
`renderer/pathtracer/CppRounding.isph`, with Imath). `PathPbmTables.cpp` and
`SpectralTables.cpp` hold no ported code, only Typhoon's vendored tables read in place,
and are tagged with the tables' license. `renderer/pathtracer/SobolBnTables.cpp`
(OpenQMC alone) and the three tests that port helide keep `Apache-2.0`.
